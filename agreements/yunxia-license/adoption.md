# Agent 与其他媒介的交付示例

以下以实际需要依赖《允夏许可证》0.9.3 的使用为前提。另有充分授权或依法可直接使用时，按相应依据及其条件判断。示例用于落实正文，不增加固定 UI、目录、表格或审批要求。

## 1. 传输内容与移交实体载体

向他人提供包含许可内容全部或部分（包括其修改形式）的副本，需要依本许可取得著作权或相关财产权许可，或者提供数据库内容需要依本许可取得数据库特别权利许可时，由提供者交付声明材料：保留随所取得内容提供且适用于本次交付部分的权利声明和署名信息，并提供许可名称、确切许可证版本及全文。内容范围和内容版本另行标明。向其他个人或组织的设备传输这些内容供其存储、显示、播放或运行，且该传输需要依本许可取得著作权或相关财产权许可时，无论临时接收还是持续保存，均由提供者履行交付条件。

| 场景 | 可采用的安排 |
|---|---|
| 经有线或无线方式向接收者设备传输内容，包括互联网、局域网、电信和广播电视传输 | 将所需声明材料与内容一起提供；也可给出明确链接，使接收者在取得内容时能够免费访问和保存这些材料。链接中的实际全文应与标明的许可证版本一致，并包含相应声明；不能只指向不断变化的“最新版”。 |
| 以纸张、存储介质等实体载体向他人移交副本 | 在副本或随附材料中提供可读取的声明材料全文；仅有二维码或网页地址不足以完成该全文交付。 |
| 同一文件包含多个来源或许可 | 按范围提供各自需要的材料，可以集中组织；主许可链接不替代第三方要求的 NOTICE、修改标记或其他交付材料。 |

分类取决于本次提供方式，不取决于是否接入互联网。通过线缆或蓝牙传送文件与递交装有副本的存储介质分属不同路径；FM 广播属于无线传输，但链接方式仍须满足取得时能够免费访问和保存声明材料的条件。若链接不能满足条件，应改用能向接收者提供完整、可读取声明材料的安排，或依已取得的其他充分授权判断。

具体结构可简化为“内容＋声明材料”，无须固定为三个文件。片段按所取得材料随附且适用于该部分的信息处理；不要求检索全部历史或网上出现过的署名。缺失信息按事实处理，不能编造作者、年份或权利声明；其他许可和法律另有要求时按其处理。

## 2. 链接变化与再次交付

可采用固定版本页面、可下载文本或与产物一同提供的声明文件；定期检查可访问性和保存版本快照是运营建议。后续继续通过传输内容并提供链接的方式交付时，重新按当次情况确认接收者能免费访问和保存；链接失效时，修复链接或直接补齐所需材料后继续交付。

先前已经符合条件的交付按当时事实判断，后续链接失效本身不倒推其不合规；先前确有缺项的交付仍按其事实和责任处理。接收者随后自行离线使用，沿用原交付的声明安排；再次向他人交付时，按新的提供方式判断：以实体载体移交副本应随附可读取的声明材料全文，经有线或无线方式传输则按相应声明安排处理。最初提供过链接不代替后续实体载体移交的全文要求。

## 3. 远程功能与实际内容传输

仅远程运行程序并返回不含许可内容的独立结果时，主许可没有据此要求交付该程序源码。浏览器下发的 JS、WASM、图形、文档或音视频，以及返回的受保护片段和数据，则按实际提供的内容判断。数据库查询应核对是否涉及特别权利；事实数据标签、条目数量或“内部使用”标签本身不代替判断。

主许可也不以源码公开作为交付方式前提，程序可交付源码、可执行形式或两者。显示、播放或运行所涉传输需要依本许可取得著作权或相关财产权许可时，提供者不能因接收方只临时接收就省略声明材料。仅依专利权限实施方案不因实施本身触发声明交付；确属另有充分授权或法定使用的，仍按其自身依据和条件判断。

## 4. 第三方与上游材料

先核对输出所含每一部分及权利的实际来源：独立备选许可足以覆盖本次相应使用时，按选中路径交付；不同部分或权利的条件按各自范围履行。仅依据本稿再许可时，来源条件继续适用，不能只换标签而移除所依赖的声明。旧版主许可或其他许可仍适用的部分，继续履行其实际条件。第三方要求随附全文时落实全文；允许链接、源码下载位置、有效书面要约或其他路径时，按该版本的范围、形式、期限和可取得性落实。单个仓库链接不自动满足所有要求。

涉及网络交互条件、修改标记、NOTICE、重链接或安装信息时，按确切上游版本及使用关系逐项处理。主许可的宽松源码安排、链接方式和补正规则不替代这些条件。

## 5. AI 输入、输出与新增条款

向其他组织的云端服务提供受保护副本时，按实际输入、权限和交付关系判断，另核服务条款。输出许可取决于实际内容：复用部分依其许可或适用法律处理，有权许可的新增部分可以选择许可。权重和数据已明确按本许可授权的部分适用本许可，其余部分按实际依据使用；账户及外部服务约定单独处理。

项目附加的服务或产品条款，应清楚区分服务安排、自有新增部分与原有内容的既有有效直接授权；该既有授权按原范围、许可证版本和条件持续。您依据本许可证使用或再许可原有许可内容时，另设条款保留接收者行使该部分权限的权利；充分独立的备选路径按所选条件判断，新增部分按其实际授权处理。原有宽松权限不自动覆盖全部新产品或新增内容，也不因本包版本更新自动改为0.9.3。署名、人身权益、隐私、品牌、保密和依法适用的付酬事项仍分别核验。

本说明没有实现或宣称已接入 Agent 自动识别、追踪或交付系统。

## 6. 按实际组合确定材料

并列收录的独立内容按各自许可提供；修改、复制嵌入或组合内容按适用条款和实际关系处理。输出目录分开、单独进程或网络接口不自动消除上游条件。若所需条件确实冲突，核对已有备选授权、补足权限、替换材料或调整有依据的组合路径后再判断。

## 历史衔接：0.9.2 迁移到 0.9.3

## 任选、累积与冲突

历史版本 0.9.0 已规定：下游另设条款应保留接收者依本许可证行使原直接授权的权限。该历史变更可能要求调整笼统限制全部复制、修改的产品条款；0.9.1 继续明确原有部分与新增部分的边界。独立新增内容及服务安排按各自范围处理。

同一内容及相应权利有真实独立可选授权时，选择足以覆盖相应使用的路径并履行其条件。不同内容或同一内容的不同权利分别适用时，所需条件按各自范围履行。仅放置两个许可证文件或写出“OR”，不能建立授权。

条件冲突时，核对已有替代授权、取得所缺权限、替换内容或调整有依据的组合方式。分文件、进程或网络连接本身不证明冲突消失。旧授权的历史留档与本次对外交付义务分别判断；充分的新直接授权不等于永远叠加全部历史版本条件。
